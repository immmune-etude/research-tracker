# Research Tracker

Personal application tracker for summer biomedical and clinical research programs — built for Eddy Yao (UCLA MCDB).

## Features

- Status tracking (Not started → Accepted)
- Materials checklist (transcript, essays, LORs, eligibility)
- Direct links to official application / program pages
- Filters by category (National, UCLA, Cancer, Cardiology, Clinical) and fit
- LocalStorage persistence with export / import backup

## Run

```bash
npm install
npm run dev
```

## Notes

Program deadlines change yearly. Always confirm dates and eligibility on the official page before applying. Seeded for the Summer 2027 application cycle.
