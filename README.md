# Internship OS — Research Tracker

Personal application tracker for Summer 2027 bioengineering internships and research programs — built for Eddy Yao (UCLA MCDB).

**Live site:** https://immmune-etude.github.io/research-tracker/

## Features

- Open now vs not-yet-open grouping
- Status tracking, materials checklist, notes
- Direct apply links with opens / deadline dates
- Industry biotech/device roles + academic research programs
- LocalStorage persistence with export / import

## Run locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Publishes the `dist/` build to GitHub Pages (`gh-pages` branch).
